# Data and code availability

The public GitHub repository is https://github.com/divinelybless/VQLS-Corrections-for-AC-Power-Flow.

**Publication status (2 November 2026):** The source manuscript and documentation are available in the repository. The complete scripts, output files, independently written interval checker, and supplementary plots are assembled in `VQLS_AC_Power_Flow_GitHub_Ready.zip` for upload. Until those files have been pushed and their contents verified in the public repository, they must **not** be described as already publicly available there.

Once the complete release is published, cite a commit SHA or a tagged release. No DOI has been assigned. A Zenodo archival deposit may provide a DOI.

The study consists of 24 fixed-seed ideal-outcome NumPy sampling experiments; it does not contain Qiskit Aer or hardware experiment results. The second interval implementation has not been externally audited.
